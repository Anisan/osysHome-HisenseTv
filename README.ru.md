# HisenseTv - Управление телевизорами Hisense

![HisenseTv Icon](static/hisensetv.png)

Система управления телевизорами Hisense на основе MQTT.

## Описание

Модуль `HisenseTv` предоставляет возможности управления телевизорами Hisense через протокол MQTT для платформы osysHome. Он обеспечивает дистанционное управление, мониторинг состояния и связывание свойств.

## Основные возможности

- ✅ **Управление MQTT**: Управление телевизором на основе MQTT
- ✅ **Управление устройствами**: Управление несколькими телевизорами Hisense
- ✅ **Связывание свойств**: Связывание элементов управления телевизором со свойствами объектов
- ✅ **Мониторинг состояния**: Мониторинг состояния телевизора
- ✅ **Поддержка команд**: Отправка команд на телевизор

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Просмотра устройств телевизоров Hisense
- Настройки параметров устройств
- Управления данными/командами телевизора
- Связывания элементов управления со свойствами

## Конфигурация

- **IP устройства**: IP адрес телевизора
- **Настройки MQTT**: Конфигурация MQTT брокера
- **ID устройства**: Уникальный идентификатор устройства

## Использование

### Добавление устройства телевизора

1. Перейдите в модуль HisenseTv
2. Нажмите "Add Device"
3. Введите IP адрес телевизора
4. Настройте параметры MQTT
5. Свяжите элементы управления со свойствами объектов

## Технические детали

- **Протокол**: MQTT
- **Тип устройства**: Умные телевизоры Hisense
- **Подключение**: MQTT клиент для каждого устройства
